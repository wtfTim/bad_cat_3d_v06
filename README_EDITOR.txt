BAD CAT 3D v2.1 — ЧИСТЫЙ ДОМ И РЕДАКТОР

Двухэтажный дом перестроен: внешние стены непрерывно стыкуются с этажами,
окна имеют настоящие проёмы, рамы и остекление. Крыша поднята над вторым этажом.

На участке остаются только базовая земля, ограда и архитектурные постройки
(гараж, сарай, баня, теплица). Мебель, деревья, дорожки, кусты,
беседки и прочий декор НЕ расставляются автоматически.

Каталог: Kenney Furniture, Kenney Nature, Tiny Living, Patio Garden, Garden Market.
Все модели добавляются вручную через кнопку «🛠️ Мебель».
Камера редактора свободная: WASD, Q/E, ПКМ/мышь, Shift и колёсико.
Перетаскивание проверяется на столкновения с архитектурными стенами и окнами.

Твои собственные предметы, добавленные ранее через редактор, остаются в
localStorage и автоматически загружаются. Если нужно чистое поле:
в редакторе нажми «Сбросить» (действие удалит локальную расстановку).
Используй «Экспорт JSON» для резервного копирования размещённых объектов.
Экспортированный JSON можно встроить в исходный код следующей сборки.

Открывай index.html через Live Server и обнови страницу Ctrl+Shift+R.
