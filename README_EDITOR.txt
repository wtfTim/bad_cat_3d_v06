Bad Cat 3D v1.9 — редактор мира
ПКМ: вращать камеру; средняя кнопка: панорамирование; колесо: зум; WASD: перемещение; Q/E: высота; Shift: ускорение.
ЛКМ: выбрать и перетащить предмет. В редакторе на телефоне используйте кнопку «Камера» для свайпа.
Выберите набор и модель, дождитесь предпросмотра, нажмите «Добавить выбранное».
Сохранить — в браузере; Экспорт JSON — переносимый файл с расстановкой. Пришлите JSON, чтобы встроить планировку в код.
