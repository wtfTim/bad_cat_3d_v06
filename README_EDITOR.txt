BAD CAT 3D v2.2 — РУССКИЙ КАТАЛОГ И СТАРТОВАЯ ОБСТАНОВКА

В редакторе добавлено поле «Категория» (гостиная, спальня, кухня, ванная,
кабинет, мебель, освещение, гараж, сарай, теплица, сад, деревья, дороги).
Названия основных предметов мебели переведены на русский:
например «Большой холодильник», «Двуспальная кровать», «Кофемашина».
Можно выбрать «Все наборы», чтобы искать сразу по всему каталогу.

ПРИМЕРНАЯ ОБСТАНОВКА:
Для нового редактора без сохранённой мебели добавляется стартовая
обстановка в доме, саду, гараже, сарае, бане и теплице.
Если у тебя уже есть расстановка, она НЕ перезаписывается.
Кнопка «🏡 Стартовая расстановка» добавляет примерные предметы к твоим
(после подтверждения). Каждую модель можно двигать, поворачивать, удалять.
Экспорт JSON сохраняет все добавленные модели и их координаты.

261 GLB-модель подключается локальным установщиком, без передачи
отдельных ассетов в публичный GitHub.
1) Распакуй BadCat_v2.2_Local_Installer.zip в папку проекта рядом с game.js.
2) Скопируй исходные шесть ZIP в папку проекта, рядом с install_packs.py.
   Либо оставь ZIP-файлы в Downloads/Загрузки.
3) Открой Terminal в VS Code и запусти: python install_packs.py
4) Установщик создаст assets/extra/ и assets/extra_catalog.json.
5) Открой index.html через Live Server и обнови страницу Ctrl+Shift+R.

Папка assets/extra/ исключена из git с помощью .gitignore.
Некоторые авторы запрещают повторное распространение ассетов как
самостоятельной библиотеки. Не выкладывай их в публичный репозиторий.

Управление редактором: ПКМ — камера, WASD — перемещение, Q/E —
высота, колёсико — масштаб, ЛКМ — выделение и перенос предмета.
