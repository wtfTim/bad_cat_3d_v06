BAD CAT 3D v1.8 — редактор мебели

Запуск: откройте index.html через VS Code Live Server.
Нажмите 🛠️ Мебель, выберите предмет кликом и перетащите мышью/пальцем.
Кнопки стрелок — перемещение по 0.25 м, ↶ ↷ — поворот.
Этаж ↑/↓ — перенос между этажами. «Поставить рядом» — добавить мебель Tiny Living.
«Сохранить» — сохранение в localStorage браузера.
«Экспорт JSON» — скачать файл расстановки, «Импорт JSON» — восстановить его на другом устройстве/браузере.
«Сбросить мебель» — вернуться к исходной расстановке.
Старые предметы Kenney восстановлены; Tiny Living является дополнением.
